# ProjectSync AI Frontend

Frontend prototype for the SIH problem statement:
"Intelligent Data Capture & Schedule-Linking Layer for Infrastructure Project Management."

## Stack
- React + Vite
- Tailwind CSS v4
- React Router
- Recharts
- Lucide React

## Run in CMD

```cmd
cd project-sync-ai-frontend
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Main routes
- /login
- /
- /schedule
- /daily-reports
- /ai-matching
- /analytics
- /alerts
- /reports
- /knowledge
- /settings
